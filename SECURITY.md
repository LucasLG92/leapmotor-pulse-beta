# Seguridad

Esta es una beta, sin promesa de soporte estable. No ejecutes controles físicos ni expongas una instalación sin revisar autenticación, TLS, actualizaciones y copias. [Privacidad](docs/PRIVACY.md) y [hosting](docs/HOSTING.md) describen el comportamiento y los requisitos actuales.

No publiques secretos, datos de vehículos, pruebas con credenciales, rutas privadas o detalles explotables en issues. Si GitHub ofrece «Report a vulnerability» para este repositorio, usa ese canal privado; si no aparece, abre únicamente una petición genérica de contacto privado, sin incluir el fallo ni datos sensibles.

Tras una exposición de credenciales, eliminar el archivo del repositorio no revoca el acceso ni borra las copias: revoca/rota el material con su proveedor. Mantén los archivos privados fuera del checkout, directorios700/archivos600 y usa placeholders en documentación. El repositorio público no incluye la instalación o las claves de ningún operador.
