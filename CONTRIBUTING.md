# Contribuir a la beta

Consulta primero [el estado y los límites](docs/BETA.md). Usa datos sintéticos para errores reproducibles y [las instrucciones de desarrollo](docs/DEVELOPMENT.md) antes de proponer un cambio. Incluye propósito, comportamiento antes/después y validaciones reales; distingue una prueba local de evidencia física con vehículo.

No adjuntes credenciales, VIN, ubicaciones, certificados, claves, capturas personales, `.env`, bases de datos, copias o logs completos. Recorta y sanea los ejemplos. Si un flujo OAuth falla, no compartas su URL completa: puede contener un código temporal.

Mantén dependencias/licencias compatibles, ejemplos genéricos, integraciones opcionales apagadas por defecto y controles físicos bloqueados hasta cualificación. No añadas endpoints del fabricante, material privado o código de aplicaciones propietarias. La aportación de código original se realiza bajo la licencia MIT del repositorio; los componentes de terceros mantienen sus condiciones.
