# PWA y aceptación observada

La interfaz web puede instalarse como PWA y ofrece una pantalla offline. Un historial de aceptación humana registra instalación, acceso offline y recepción de avisos en dispositivos iOS y Android concretos; una notificación de prueba también se recibió mientras el dispositivo estaba bloqueado. Son observaciones reportadas para interacciones y revisiones anteriores, no una comprobación automatizada ni una certificación del candidato actual.

Las observaciones no acreditan compatibilidad universal, la entrega general de Web Push, el relevo del service worker en una instalación actual, accesibilidad con VoiceOver o TalkBack, caché privada, consumo de batería, widgets nativos, autenticación tras reinicio, vehículo ni aceptación del producto completo. No se publican modelos de teléfono, dominio, datos de una instalación ni recibos personales.

La QA de navegador usa datos sintéticos y cubre rutas, estados offline simulados y actualización explícita del worker. Las pruebas locales registradas en [VALIDATION.md](VALIDATION.md) no sustituyen Safari/Chrome en teléfonos reales. Las condiciones de aceptación pendientes permanecen en [ACCEPTANCE.md](ACCEPTANCE.md) y [DELIVERY-STATUS.json](DELIVERY-STATUS.json).
