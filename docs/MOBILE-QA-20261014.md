# Reflujo y foco en pantallas móviles

Con texto ampliado, los botones de Diario podían superponerse y las rejillas de
Coche, Perfil y Energía fragmentaban etiquetas. Se permite reflujo de acciones
y se ajustan columnas según el espacio y la fuente. En pantallas de poca altura,
el primer campo de un trayecto se desplaza al recibir foco para que la barra
inferior no lo tape. Cancelar la salida conserva el borrador.

Validación de navegador con datos sintéticos: seis rutas a320/390/430px,
claro/oscuro, texto raíz32px y formulario a320×450. Los seis flujos automáticos
incluyen controles sin solapamiento, hit-testing del campo enfocado y descarte
cancelado, además de consultas diferidas, reintento idempotente y respuestas
fuera de orden. Svelte0errores/0avisos y build web correcto. No se altera la API
ni el esquema de datos y no hay nuevas dependencias de producción.

La revisión con Chromium y los árboles accesibles no acredita teclado,
VoiceOver/TalkBack o navegadores en teléfonos reales. Esa aceptación sigue
pendiente. Los APK/IPA genéricos sin firma son artefactos de compilación y no
actualizaciones instalables. La [CI iOS38487389431](https://github.com/LucasLG92/leapmotor-pulse-beta/actions/runs/38487389431)
acredita App/WidgetKit y arranque genérico de este reflujo sobre801a19b.
Se contrastaron los108 archivos fuente y todos los hashes del IPA; permanecen
pendientes firma, configuración, instalación, login y widgets en teléfonos.

Los recursos visuales, temas, formularios y funciones existentes se conservan.
La PWA ofrece el relevo de versión de forma voluntaria y protege los borradores.
La interfaz está desplegada por HTTPS:37 recursos y26 versiones gzip coinciden
con el paquete revisado; salud y readiness correctas. La API privada rechaza
consultas sin autenticación y un token sintético inválido. Backend y esquema
se conservan. Recibo: [MOBILE-REFLOW-RELEASE-20261014.json](MOBILE-REFLOW-RELEASE-20261014.json).
