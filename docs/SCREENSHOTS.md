# Capturas de Pulse

Esta galería muestra la interfaz de Pulse en una instancia local con datos de prueba. La etiqueta visible «Lucas» no identifica una sesión de la instalación privada. No contiene telemetría ni datos privados de un B10; las coordenadas de Mapa son valores de ejemplo públicos del producto. La ilustración del coche es orientativa.

Estas imágenes documentan el aspecto de la interfaz; no demuestran funcionamiento con un vehículo, sensores, cámaras, centinela, servicios externos ni pruebas físicas en teléfonos.
